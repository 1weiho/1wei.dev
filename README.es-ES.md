# Mi Sitio Web Personal

Este es el código fuente de mi sitio web personal, construido con [Next.js](https://nextjs.org).

¡Siéntete libre de visitar mi sitio web para saber más sobre mí!

## Características

- Construido con Next.js para una experiencia web moderna y de alto rendimiento.
- Diseño limpio y minimalista para mostrar información personal.

## Instalación

Si deseas explorar este proyecto, puedes clonar el repositorio y ejecutarlo localmente:

```bash
git clone https://github.com/1weiho/1wei.dev.git

cd 1wei.dev

pnpm i

pnpm dev
```

## Optimización de Imágenes

Todas las imágenes en la carpeta public utilizan la extensión de Raycast [Image Modification](https://www.raycast.com/HelloImSteven/sips), usando el comando `Optimize Images` con un parámetro de Power 60.
